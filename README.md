# FamilyStorageApp

## Game Design Document resources

新しいゲーム企画を要件定義から進めるためのドキュメントを `docs/` に用意しています。

- `docs/game-requirements-workshop.md`
  - ペルソナ、体験コンセプト、プラットフォーム、MVP範囲などを選択式で整理するワークシート
- `docs/gdd-template.md`
  - 今回の企画内容を転記し、次回以降も再利用できるGDDテンプレート

まずはワークシートのStep 1から順に選択し、決まった内容をGDDテンプレートへ反映してください。
