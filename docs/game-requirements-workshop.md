# Game Requirements Workshop

このワークシートは、新しいゲーム企画の要件定義を会話形式で進めるためのものです。  
各項目は「まず選ぶ」「理由を書く」「GDDへ反映する」の順で埋めます。

## 使い方

1. 各ステップで、選択肢から最も近いものを選ぶ
2. 迷う場合は「第1候補」「第2候補」を残す
3. 決定した内容を `docs/gdd-template.md` の該当セクションへ転記する
4. 企画が固まるまでは、未決定事項を無理に確定しない

### 2-2. ペルソナ候補

近いものを選ぶか、独自に書き換えてください。

#### Persona A: すきま時間で遊ぶライトプレイヤー

- 年齢: 20代から40代
- 生活: 通勤、家事、休憩中にスマホを触る
- 遊ぶ時間: 1回3分から10分
- 好む体験: わかりやすい成長、毎日の小さな報酬
- 避けたいもの: 長いチュートリアル、複雑すぎる操作

#### Persona B: 攻略を楽しむ戦略プレイヤー

- 年齢: 20代から40代
- 生活: 夜や休日にまとまって遊ぶ
- 遊ぶ時間: 1回30分以上
- 好む体験: 編成、最適化、高難度クリア
- 避けたいもの: 運だけで決まる勝敗、浅い成長要素

#### Persona C: 物語と世界観を味わうプレイヤー

- 年齢: 10代後半から40代
- 生活: 好きな作品を深く追う
- 遊ぶ時間: 1回15分から60分
- 好む体験: キャラクター、謎、探索、感情移入
- 避けたいもの: 世界観と合わないUIや課金圧

#### Persona D: 家族や友人と遊ぶカジュアルプレイヤー

- 年齢: 幅広い
- 生活: 家族、友人、パーティーで遊ぶ
- 遊ぶ時間: 1回5分から30分
- 好む体験: 笑い、共有、直感的なルール
- 避けたいもの: 説明が長い、実力差が出すぎる

#### Persona E: 配信映えを重視する視聴者・配信者

- 年齢: 10代から30代
- 生活: 動画サイトやSNSでゲームを知る
- 遊ぶ時間: 視聴は短時間、プレイは不定期
- 好む体験: ハプニング、見どころ、リアクション
- 避けたいもの: 画面変化が少ない、見ても伝わりにくい面白さ
