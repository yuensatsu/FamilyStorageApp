## 2. ターゲットとペルソナ

### 2.1 ターゲットセグメント

以下から主ターゲットを1つ、必要に応じて副ターゲットを1から2つ選びます。

| セグメント | 特徴 | 期待される体験 |
| --- | --- | --- |
| カジュアル層 | 短時間、直感操作、低ストレスを好む | すぐ楽しい、失敗しても疲れない |
| コアゲーマー層 | 深い攻略、上達、やり込みを好む | スキル成長、戦略性、達成感 |
| ストーリー重視層 | 世界観、キャラクター、感情体験を重視 | 没入、共感、余韻 |
| クリエイティブ層 | 作る、飾る、共有する体験を好む | 自己表現、コレクション、共有 |
| ソーシャル層 | 協力、対戦、話題化を重視 | 一緒に遊ぶ、競う、語れる |
| 学習・知育層 | 学び、習慣化、親子利用を重視 | 成長実感、安全性、継続 |
